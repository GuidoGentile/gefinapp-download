# GefinApp — download ufficiale

Questo repository pubblico ospita il sito di presentazione e le release Windows di GefinApp.

## Installazione

1. Apri la sezione **Releases**.
2. Scarica `GefinApp-<versione>-win-x64.zip` e, facoltativamente, il file `.sha256`.
3. Estrai completamente lo ZIP in una cartella scrivibile.
4. Fai doppio clic su `Avvia GefinApp.cmd`.

Il runtime è incluso. Al primo avvio l’app crea localmente `data/gefin.db`; nessun database
personale è incluso nel download.

## Stato del progetto

GefinApp è una beta sperimentale per Windows x64. Il pacchetto non è ancora firmato digitalmente.
Il codice sorgente applicativo è mantenuto in un repository privato; questo repository distribuisce
il pacchetto eseguibile, le istruzioni e le note di versione.

## Avvertenza

GefinApp è uno strumento informativo e di ricerca. Non costituisce consulenza finanziaria,
sollecitazione all’investimento o garanzia di rendimento. Dati, indicatori e previsioni possono
essere incompleti, differiti o errati.
