Architettura local-first

Il database nasce sul tuo PC.

Nessun database personale nel download. Al primo avvio GefinApp crea un nuovo file SQLite nella propria cartella.

Nessun account GefinApp. Portafoglio, simulazioni e preferenze restano nell’installazione locale.

Integrazioni facoltative. L’app funziona con fonti pubbliche; Fineco XCell è opzionale e non serve per iniziare.

Tre passaggi

Scarica, estrai, avvia.

  1. 1
    Scarica lo ZIP

    Apri la Release più recente e scegli il pacchetto Windows x64.

  2. 2
    Estrai la cartella

    Non avviare il file direttamente dall’archivio compresso.

  3. 3
    Apri “Avvia GefinApp.cmd”

    Il server locale parte in background e l’app si apre nel browser predefinito.
